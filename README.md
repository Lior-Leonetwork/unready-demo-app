# quickcart

A tiny vibe-coded shop backend: Express + Postgres + Stripe checkout with image uploads.

> **This repository is a test fixture.** It is deliberately production-unready and
> exists to demo the [Spaces](https://spaces-production-9f1e.up.railway.app) readiness
> scanner. **Every credential in this repo is fake** and matches nothing real.

Run it:

```bash
npm install
npm start
```
